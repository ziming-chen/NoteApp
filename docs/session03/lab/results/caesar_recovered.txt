Every evening, the teacher checks the exercise sheets before leaving the classroom. The students write clear sentences and explain the reasons behind each answer. They review their mistakes together because the purpose of the lesson is to understand the method, rather than remember a secret answer. A careful reader notices that some letters appear much more often than others in an ordinary English message.

The security lesson begins with a simple example. A message is readable before encryption, and a secret key changes the message into ciphertext. The receiver needs the same key to reverse the change and recover the original message. If every letter is moved by the same number of places, repeated letters still leave repeated patterns. Even when the key is unknown, these patterns give the reader evidence about the meaning of the text.

Modern encryption requires more care. The algorithm can be public, but the key must remain secret. A strong algorithm does not make every method of using it safe. Equal blocks reveal structure when they produce equal encrypted blocks. An authenticated mode also checks whether someone changed the encrypted message. The experiment compares these ideas with a picture and records the observed results, so the reader can see what each method protects.
